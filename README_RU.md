# VINYL — нативное приложение iPhone (бесплатная сборка)

Проект на SwiftUI + WidgetKit. Для **Windows + iPhone**, без собственного Mac и без платной Apple Developer Program.

> **Статус:** исходники прошли локальную синтаксическую проверку Swift, YAML и целостности архива. Собрать IPA и проверить установку/Spotify-вход на физическом iPhone в этой среде нельзя. GitHub Actions выполнит настоящую компиляцию через Xcode. Если она выдаст ошибку, понадобится исправление по журналу сборки.

## Что готово

- Нативное приложение VINYL для iOS 17+.
- Spotify OAuth2 PKCE; Client ID вводится **в приложении** (не в публичном репозитории), токены — в Keychain.
- Ручное добавление альбомов **по ссылке Spotify без Premium и без входа в Spotify Developer API**. Название и обложка через публичный oEmbed, автор и год заполняются вручную при необходимости.
- Сохранённые альбомы Spotify (`GET /me/albums`, до 1000 альбомов за один запуск) и последние прослушивания (`GET /me/player/recently-played`), кеш на устройстве.
- Карточка альбома и мягкий цветовой фон по обложке; переход в Spotify; случайный и ручной выбор, поиск и оценки 1–10.
- Нативный **средний** WidgetKit-виджет: обложка, название, исполнитель, год, переход в Spotify, отдельная кнопка Shuffle.
- Загрузка обложки виджета через публичный Spotify oEmbed API.

### Честное ограничение бесплатной версии

Бесплатная подпись Apple ID **не поддерживает App Groups**, поэтому приложение и расширение WidgetKit не имеют общего хранилища. В этой первой версии **приложение** показывает и синхронизирует реальную медиатеку пользователя, а **виджет** независимо переключает встроенные четыре альбома: Flower Boy, IGOR, Blonde, Scorpion. Ручной выбор в приложении на виджет пока не влияет. Это намеренно, чтобы сборка не зависела от платных entitlements. Виджет обновляется по правилам iOS; нажатие Shuffle может привести к задержке перерисовки.

Spotify в режиме разработки требует, чтобы владелец Spotify Developer-приложения имел Spotify Premium (требование Spotify с 2026 года). Если Premium уже есть, дополнительной оплаты за разработку Spotify нет. **Если Premium нет, приложение всё равно работает с альбомами, добавленными по ссылкам**; автоматическая синхронизация всей библиотеки не будет доступна. Для автоматической синхронизации используй собственный существующий Developer Client ID или создай доступный идентификатор в Spotify Developer Dashboard.

## Пошагово: сборка на GitHub (Windows)

1. Создай бесплатный аккаунт https://github.com/ (если его нет).
2. Создай новый **публичный** репозиторий, например `vinyl-ios`. Публичность нужна для бесплатного стандартного macOS-раннера GitHub Actions. **Не добавляй в репозиторий пароли, токены Spotify и Apple ID.** В исходниках их нет.
3. Распакуй этот ZIP на Windows. Загрузи **содержимое папки** `VinylOfTheDay-iOS` в корень репозитория через `Add file` → `Upload files` → `Commit changes`. Важно, чтобы в корне лежал `project.yml`, а файл `.github/workflows/ios-ipa.yml` попал именно в скрытую папку `.github`. Удобнее всего использовать GitHub Desktop или Git, потому что браузерная загрузка скрытых папок может быть неудобной.
4. Открой вкладку **Actions** → `Build unsigned iPhone IPA` → `Run workflow` → `Run workflow`.
5. После окончания сборки открой выполненный workflow → **Artifacts** → `VINYL-unsigned-IPA`, скачай ZIP-артефакт и распакуй из него `VINYL-unsigned.ipa`.
6. Если сборка красная, открой журнал `Build iOS device app without signing`; там будет конкретная ошибка Xcode. Это не связано с Apple ID.

Этот IPA **ещё не подписан**. Его нельзя просто открыть на iPhone через «Файлы» — нужна подпись при установке.

## Пошагово: установить IPA на iPhone с Windows

1. Установи [AltServer / AltStore Classic](https://altstore.io/) по [официальной инструкции для Windows](https://faq.altstore.io/altstore-classic/how-to-install-altstore-windows). Обычно нужны iTunes и iCloud для Windows и кабель к iPhone.
2. Через AltServer установи AltStore Classic на iPhone, войдя в обычный бесплатный Apple ID.
3. На iPhone разреши разработчика: **Настройки → Конфиденциальность и безопасность → Режим разработчика** (если появится) и доверь профиль в **Настройки → Основные → VPN и управление устройством**.
4. Перенеси `VINYL-unsigned.ipa` на iPhone: AirDrop, iCloud Drive, мессенджер/«Файлы» или другой удобный способ.
5. Открой AltStore Classic → **My Apps** → `+` → выбери IPA. AltStore подпишет и установит приложение с бесплатным Apple ID.
6. Если AltStore предложит управлять расширениями, сохраняй **VinylWidget**: без `.appex` нативного виджета не будет. Используются два App ID (основное приложение и расширение), лимит бесплатного аккаунта — 10 App ID в 7 дней.
7. Приложение установлено. Открой **VINYL**. Потом зажми домашний экран → добавь виджет `VINYL` среднего размера.

**Подпись бесплатного Apple ID действует 7 дней.** Чтобы VINYL и виджет продолжали запускаться, нужно обновлять подпись через AltStore/AltServer. Бесплатная установка без повторного подписания на обычном iPhone здесь не обещается. WidgetKit/AltStore совместимость зависит от текущей версии iOS; если виджет не появился, сначала проверь, что расширение не было удалено при установке.

## Spotify: настройка авторизации

1. Открой https://developer.spotify.com/dashboard и открой приложение разработчика (то же можно использовать для Scriptable, если Spotify позволяет добавить ещё один Redirect URI).
2. В **Redirect URIs** добавь точно `vinyl-of-day://callback` и сохрани. В Bundle ID, если требуется: `com.vinyl.day.app` (учти, что AltStore может переписать Bundle ID при подписи; если Spotify требует точного совпадения, скорректируй в Dashboard).
3. Скопируй **Client ID**, не Client Secret.
4. В установленном приложении VINYL открой **Настройки**, вставь Client ID → **Сохранить** → **Войти через Spotify** → разреши доступ.
5. Нажми **Синхронизировать альбомы**. В «Сегодня» выбери библиотеку или недавнее, в «Коллекция» — нужный альбом и оценку.

**Если Premium нет:** не подключай Spotify Developer. Открой вкладку «Коллекция» → `+` → вставь Spotify-ссылку на альбом → при желании укажи артиста и год. В «Сегодня» выбери режим «По ссылкам». Spotify будет открываться при нажатии на альбом, но без автоматического доступа к твоей сохранённой медиатеке.

Используется системный `ASWebAuthenticationSession`, Spotify OAuth PKCE и URL-схема для возврата в приложение. Если Spotify Dashboard не принимает custom scheme, это ограничение настройки Spotify — потребуется HTTPS Universal Link и дополнительная конфигурация; не используй случайные сторонние callback-сервисы для доступа к токенам.

## Что дальше

Для настоящей синхронизации виджета с медиатекой без App Groups понадобится другой механизм обмена данными (например, отдельный защищённый backend с синхронизацией **только метаданных**, без публикации Spotify-токенов). Такой backend в данном MVP **не включён**. Это следующий этап, а не якобы готовая функция.

## Структура проекта

- `project.yml` — спецификация XcodeGen, автоматическое создание Xcode-проекта.
- `.github/workflows/ios-ipa.yml` — облачная сборка Mac/Xcode и unsigned IPA.
- `App/` — основное SwiftUI-приложение, вход Spotify, коллекция, оценки.
- `WidgetExtension/` — отдельный нативный WidgetKit-виджет + AppIntent Shuffle.
- `Shared/` — общие структуры данных, дизайн и пресеты.

**Безопасность:** не публикуй Apple ID, Client Secret, access/refresh tokens. Публичный GitHub-репозиторий содержит лишь код, который разрешено видеть другим. На GitHub сборка происходит без твоих Apple/Spotify учётных данных.
